# gym-tracker
Tracker personal pentru antrenamentele de la sală: template-uri, reps, kg și evoluție în timp.

Aplicație web simplă (HTML, CSS, JavaScript, fără biblioteci), gândită pentru telefon.
Datele se salvează doar în browserul telefonului (localStorage). Nu există server sau cont.
Merge și fără internet (PWA) și se poate adăuga pe ecranul principal.

Fă backup din pagina **Backup** (fișier .json), mai ales înainte să schimbi telefonul sau să ștergi datele browserului.
